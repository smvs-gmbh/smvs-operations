# RTM-001 — Requirements traceability matrix

Draft v0.2, 2026-11-17. Owner SMVS GmbH. Candidate implementation
`d446f5d2d6913403da53ab8ce41df76f5e65ccfe`. Release scope and approvers remain
subject to confirmation under [VP-001](../VP-001%20Validation%20Plan.md).

Sources are [URS-001](../requirements/URS-001%20User%20Requirements%20Specification.md)
v0.10, [Core FRS](../requirements/FRS-CORE-001.md) v0.1,
[Exceptions FRS](../requirements/FRS-EXCEPTIONS-001.md) v0.1,
[Integration FRS](../requirements/FRS-IMPORT-001%20Information%20Integration%20Framework.md)
v0.3 and [RA-001](RA-001.md) v0.2. Ranges are inclusive.

- **Local evidence** means representative automated checks have passed against
  the candidate. Formal acceptance remains open.
- **Partial** means candidate evidence covers only part of the requirement.
- **Open** means the requirement, functional specification or supporting
  evidence still needs work or a scope decision.
- **Planned** means a later capability or a work item awaiting a release scope
  decision. No formal pass is assigned to any row.
